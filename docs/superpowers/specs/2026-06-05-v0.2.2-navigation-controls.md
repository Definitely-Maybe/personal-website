# v0.2.2：页面导航与浏览控制优化

日期：2026-06-05

## 版本目标

本版本聚焦公开站点的浏览定位感与控制感。

v0.2.1 已完成书影音内容体验、分页、空状态和桌面左侧导航固定。v0.2.2 在此基础上继续打磨用户浏览长页面、进入详情页、切换筛选和翻页时的体验，让站点更像一个安静但可控的私人内容空间。

核心目标：

- 进入详情页后，用户知道自己从哪里来、如何退出阅读。
- 列表页分页控件更通用，支持直接跳到特定页面。
- 随笔筛选时布局保持稳定，不因卡片数量变化造成宽度抖动。
- 桌面端滚动时，上方标题与关键子导航保持可见。

## 需求范围

### 1. 详情页面包屑与退出阅读

覆盖页面：

- 随笔详情页：`/essays/[slug]`
- 书影音详情页：`/reviews/[slug]`

要求：

- 详情页左上方增加面包屑路径。
- 随笔详情路径为：`首页 / 随笔 / 当前标题`。
- 书影音详情路径为：`首页 / 书影音 / 音乐/书籍/影视 / 当前标题`。
- 增加“退出阅读”入口。
- “退出阅读”固定返回对应列表页：
  - 随笔详情返回 `/essays`
  - 书影音详情返回 `/reviews`
- 该入口不依赖浏览器历史，避免从直接链接进入时行为不确定。
- 视觉应轻、克制，不能像后台工具栏或强按钮。

可接受实现：

- 可抽象为通用详情页导航组件。
- 404 状态可提供返回列表或返回首页入口，但不强制使用完整面包屑。

### 2. 通用分页控件

覆盖页面：

- 随笔列表页：`/essays`
- 书影音列表页：`/reviews`

要求：

- 将现有“上一页 / 下一页”分页升级为更通用的分页控件。
- 保留上一页、下一页能力，但用箭头样式表达。
- 增加跳到第一页、跳到最后一页能力，可用双箭头样式表达。
- 中间显示可点击页码。
- 当前页高亮，风格接近现有分类 chip / tab，而不是后台表格分页。
- 筛选或 tab 切换后，分页状态应合理重置到第一页。
- 随笔与书影音共用组件和尽可能一致的交互逻辑。

交互约束：

- 页码数量较少时可全部显示。
- 页码数量较多时可采用轻量省略策略，但本版本不需要复杂跳页输入框。
- 分页控件隐藏或出现时，不应造成列表宽度变化。

### 3. 修复随笔筛选卡片宽度抖动

覆盖页面：

- 随笔列表页：`/essays`

问题描述：

- 当前切换年份或标签筛选时，随笔卡片宽度会变化，造成视觉抖动。

要求：

- 切换年份 / 标签筛选时，随笔卡片宽度保持稳定。
- 列表区域不因筛选结果数量、空状态显示、分页控件显示隐藏而重新挤压。
- 筛选后仍重置到第一页。
- 空状态仍能正常出现。

优先级：

- 桌面端优先。
- 移动端不作为本轮重点，但不能明显破坏现有可读性。

### 4. 桌面端标题区与子导航固定

覆盖页面：

- 首页
- 随笔列表页
- 随笔详情页
- 书影音列表页
- 书影音详情页
- 时间线页
- 访客簿页
- 关于页

要求：

- 桌面端向下滚动时，页面上方标题区压缩后固定在视口顶部。
- 关键子导航 / 控件跟随固定：
  - 书影音：音乐 / 书籍 / 影视 tab。
  - 随笔：年份 / 标签筛选入口或筛选控件。
  - 详情页：面包屑与“退出阅读”入口。
  - 其他页面：标题区固定即可。
- 首屏仍保留当前舒展的大标题与说明文字。
- 滚动后采用“标题压缩后固定 + 子 tab 固定”的 B 方案。
- 固定区域背景应与站点纸感背景协调，避免透明导致内容互相覆盖。
- 固定区域不能遮挡正文内容；正文顶部应预留合理空间。

视觉方向：

- 克制、轻、内容优先。
- 不做强工具栏、不做重阴影、不做明显后台式 sticky header。
- 可以使用细边线、轻背景、轻微透明或模糊，但不要形成强卡片感。

## 非目标

本版本不做：

- Sanity schema 调整。
- 新内容类型。
- 登录、真实 AI、RAG、私密内容库。
- 真实访客簿后端。
- 时间线横向数轴重构。
- 移动端导航系统重构。
- 复杂分页输入框或服务端分页。

## 实现建议

### 组件层

建议新增或调整：

- `Breadcrumbs`：通用面包屑组件。
- `DetailNav` 或类似组件：承载面包屑与退出阅读。
- `Pagination`：升级为带首页、上一页、页码、下一页、末页的通用组件。
- `StickyPageHeader` 或扩展 `ContentLayout`：统一管理标题区固定体验。

### 页面层

建议优先避免每个页面手写一套 sticky 结构。

`ContentLayout` 已经承载公开内容页标题区，适合作为统一入口。但不同页面有不同子导航，因此可以考虑为 `ContentLayout` 增加插槽，例如：

- 默认标题区。
- 固定状态下的紧凑标题。
- 标题区下方的 controls 插槽。

也可以先以最小改动实现，再在代码组织上抽出共享组件。

### 前端交互

分页逻辑应从随笔页和书影音 tab 中抽出共享脚本或共享模式，减少两处行为不一致。

随笔筛选宽度抖动优先从 CSS 布局稳定性处理：

- 固定列表区域 grid/flex 轨道。
- 避免筛选结果数量变化影响外层列宽。
- 分页 / 空状态隐藏显示时不改变主内容宽度。

## 验收标准

- 随笔详情页显示面包屑和“退出阅读”，点击后回到 `/essays`。
- 书影音详情页显示面包屑和“退出阅读”，点击后回到 `/reviews`。
- 随笔分页支持首页、上一页、指定页、下一页、末页。
- 书影音每个分类 tab 的分页支持首页、上一页、指定页、下一页、末页。
- 切换书影音 tab 后，当前分类分页回到第一页。
- 切换随笔年份或标签筛选后，分页回到第一页，卡片宽度不明显变化。
- 桌面端滚动时，页面标题区压缩并固定，关键子导航保持可见。
- 固定标题区不遮挡正文内容。
- 现有单元测试、构建和 e2e 测试通过。

## 风险与注意事项

- sticky 标题区可能与左侧固定导航、页面滚动条、内容顶部间距互相影响，需要桌面端视觉 QA。
- 如果使用透明或模糊背景，需要确认正文经过时不会影响阅读。
- 分页组件升级后，需要确保无内容、少于一页、多页、筛选后无结果等状态都正常。
- 详情页的“退出阅读”不保留书影音 tab 状态；这是本版本有意简化，后续如需要可再增加 URL query 或 hash 状态。
