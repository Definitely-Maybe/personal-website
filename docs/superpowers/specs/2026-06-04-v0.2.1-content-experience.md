# v0.2.1 书影音体验与内容浏览基础优化规格

## 版本定位

v0.2.1 是 v0.2.0 接入 Sanity 内容后台后的体验整理版。

这一版的主线是把“书影音”从简单作品卡片，推进为更适合长期记录的私人书影音索引：它应同时表达作品本身、我记录它的时间、我的评分和短评，也允许为部分作品写长评。

这一版也顺手补齐内容列表在桌面端的基础浏览体验，包括空状态、分页和左侧导航固定。它们服务于同一个问题：当 Sanity 中的公开内容逐渐变多或暂时为空时，前台页面仍然安静、有序、可读。

这一版暂时不做移动端系统优化，不做时间线横向数轴。移动端只要求不被本版本改动明显破坏，后续可以单独规划。

## 产品原则

- 网站仍然是中文个人网站 / 个人博客，不做内容平台感。
- UI 延续极简、温和、内容优先的风格。
- 书影音记录服务于私人记忆和整理，不服务于客观排名。
- 评分展示应清楚，但不做成商业点评网站的强刺激视觉。
- 列表控制和分页应轻，不使用后台表格式控件。
- 内容为空时不显示大片空白，也不使用夸张插画或强提示。
- 不提前加入登录、真实 AI、RAG、真实访客簿、私密内容库等未来方向。

## 范围总览

v0.2.1 纳入：

- 书影音三类默认封面。
- 修复书影音子 tab 分类异常。
- 书影音展示我的记录 / 评分时间。
- 书影音评分展示改为 `4.3/5` 和五颗星。
- 书影音详情页。
- 长评作为书影音详情页的可选主体内容。
- 书影音分页。
- 随笔分页。
- 随笔、书影音、时间线空状态。
- 桌面端左侧导航固定。

v0.2.1 不纳入：

- 时间线横向数轴。
- 移动端导航系统优化。
- 访客簿真实提交。
- 站内后台或 `/admin` 页面。
- 登录、权限、用户系统。
- 真实 AI 聊天。
- RAG 或私密资料管理。
- 把私人笔记、人格说明书、ChatGPT 历史或私密 RAG 材料提交到公开仓库。

## 书影音内容模型

### 作品年份与记录时间

书影音需要同时保留两类时间：

- `year`: 作品发布、出版或上映年份。
- `date`: 我的记录、评分或写下这条书影音笔记的日期。

前台展示时不能只显示作品年份。卡片中应保留作品年份，同时以轻量方式显示我的记录时间，例如：

```txt
The Weeknd · 2020
记录于 2026.06.04
```

实现时可以继续沿用 v0.2.0 的 Sanity 字段 `date`，但 Studio 中的中文标题和前台展示语义应明确它是“记录 / 评分日期”，不是作品发布日期。

### 评分

评分改为 0 到 5 分制存储，支持一位小数，例如 `4.3`。

前台展示调整为：

- 文本评分：`4.3/5`。
- 五星展示：直接按 5 分制渲染。

星星精度规则：

```txt
starFill = rating / 5
```

示例：

- `5.0/5`: 五颗星全亮。
- `4.3/5`: 四颗星全亮，第五颗星填充 30%。
- `4.0/5`: 四颗星全亮。
- `3.7/5`: 三颗星全亮，第四颗星填充 70%。

视觉要求：

- 星星应小而克制。
- 星星需要支持 0.1 颗星精度，而不是只区分整星或半星。
- 满星、局部填充星和空星状态需要稳定，不因字体或容器变化造成布局跳动。
- 数字评分仍然可读，星星是辅助视觉，不替代数字。
- 如果实现采用 CSS 遮罩、叠层或内联 SVG，应保证不同小数评分下星星总宽度不变化。

### 长评与详情页

所有已发布书影音条目都可以进入详情页。

理由：

- 交互规则稳定，用户不需要猜哪些卡片可以点击。
- 没有长评的条目也可以展示基础信息、短评、标签、记录时间和评分。
- 未来给某条记录补长评时，不需要改变列表交互。

详情页路径建议：

```txt
/reviews/[slug]
```

详情页内容：

- 标题。
- 类型。
- 创作者。
- 作品年份。
- 我的记录 / 评分时间。
- 评分数字和五星。
- 封面。
- 短评。
- 标签和记忆点。
- 长评正文。

长评规则：

- `body` 有内容时，详情页以长评作为主体内容。
- `body` 为空时，详情页展示基础信息和短评，并使用温和文案说明“这条记录目前只有短评”。
- 列表页中，有长评的条目可以出现轻量提示，例如 `长评` 或 `阅读全文`。
- 没有长评的条目仍然可点击进入详情页，但不使用强烈的“阅读全文”提示。

## 书影音默认封面

书影音需要三类默认封面：

- 音乐默认封面。
- 书籍默认封面。
- 影视默认封面。

要求：

- 三张默认封面可以使用生图模型生成 bitmap 图片资产。
- 三张图风格统一，但类型辨识清楚。
- 没有上传封面时，根据 `category` 自动选择默认封面。
- 不再让所有缺失封面的内容 fallback 到 `After Hours` 封面。
- 默认封面不应包含真实版权作品、真实专辑封面、真实电影剧照或可识别商标。
- 图片应放入公开静态资源目录，并使用稳定文件名。

建议资源路径：

```txt
public/covers/reviews/default-music.png
public/covers/reviews/default-book.png
public/covers/reviews/default-film.png
```

## 书影音列表与 tab

书影音子 tab 需要按 `category` 正确过滤：

- 音乐 tab 只展示 `category = music`。
- 书籍 tab 只展示 `category = book`。
- 影视 tab 只展示 `category = film`。

切换 tab 时：

- 内容区域应立即更新。
- 当前分类分页应回到第一页或保持该分类自己的有效页码。
- 不应出现其他分类内容混入。
- 桌面端布局需要稳定，不因 tab 切换产生明显跳动。

列表卡片建议展示：

- 封面。
- 创作者和作品年份。
- 标题。
- 短评。
- `4.3/5` 评分。
- 五星评分。
- 我的记录时间。
- 标签。
- 长评提示。

## 分页

分页用于避免内容无限纵向堆叠。

### 随笔分页

随笔列表默认每页 6 篇。

要求：

- 仍保留现有标签或年份筛选能力。
- 筛选条件变化后，分页状态应回到第一页。
- 当前筛选结果不足一页时，不显示分页控件。
- 分页控件应轻量，避免后台表格分页感。

### 书影音分页

书影音默认每个分类每页 6 条。

要求：

- 音乐、书籍、影视各自分页。
- 切换 tab 后，显示该分类第一页或该分类自己的有效页码。
- 分类内容不足一页时，不显示分页控件。
- 分页控件位置应靠近内容列表底部，不能抢走卡片主体注意力。

## 空状态

当内容列表为空时，不显示大片空白。

覆盖页面：

```txt
/essays
/reviews
/timeline
```

空状态要求：

- 页面标题、描述和基本结构仍然完整。
- 文案温和、克制，不使用系统错误口吻。
- 空状态应适配“完全没有内容”和“筛选后没有结果”两种情况。
- 不要求访客采取行动，不出现后台入口或编辑提示。

文案方向示例：

```txt
这里还没有公开的记录。
```

```txt
这个分类暂时是空的，之后再慢慢补上。
```

具体文案可在实现时根据页面语气调整，但不能显得像 SaaS 空数据提示。

## 左侧导航固定

桌面端右侧内容滚动时，左侧导航栏应保持在视口内。

要求：

- 桌面端左侧导航固定或 sticky。
- 右侧主内容可以正常纵向滚动。
- 左侧导航不应随长内容一起离开视口。
- 固定后的导航不能遮挡主内容。
- 保持当前侧栏的清淡视觉，不增加沉重阴影或强烈背景。

移动端暂不在 v0.2.1 系统优化。实现时不要为了桌面固定而让移动端导航更拥挤。

## Sanity 与内容安全

v0.2.1 继续使用独立 Sanity Studio。主站不新增 `/admin` 页面。

Sanity review schema 可以按需要调整字段标题、校验和说明，但不应要求重新创建已有内容。已有 v0.2.0 示例内容应能继续显示。

前台只展示已发布内容。草稿不能出现在：

- 书影音列表页。
- 书影音详情页。
- 随笔列表页。
- 时间线页。

不得提交：

- `.env`。
- Sanity token。
- 私人人格说明书。
- ChatGPT 历史。
- 近期状态摘要。
- 私人笔记。
- 私密 RAG 材料。

## 页面与路由

需要新增或调整的页面：

```txt
/reviews
/reviews/[slug]
/essays
/timeline
```

不新增：

```txt
/admin
```

## 测试与验证

完成后需要验证：

- `npm run test` 通过。
- `npm run build` 通过。
- `npm run test:e2e` 通过。
- `studio` 内 `npm run build` 通过。

测试应覆盖：

- 书影音 tab 按 `category` 过滤。
- 缺失封面按分类选择默认封面。
- 评分展示可按 5 分制渲染为 0.1 精度五星。
- 有长评和无长评的书影音详情页都能访问。
- 草稿内容不会出现在前台。
- 随笔分页在筛选变化后回到合理状态。
- 空状态不会导致页面结构缺失。

视觉 QA 应重点查看桌面端：

- 书影音列表卡片密度。
- 默认封面是否统一且能区分类型。
- 数字评分和五星是否协调。
- 书影音详情页是否仍然私人、安静、内容优先。
- 分页控件是否轻。
- 左侧导航固定后是否遮挡或压迫主内容。

## 验收标准

v0.2.1 完成后应满足：

- 书影音音乐、书籍、影视 tab 分类正确。
- 缺失封面的书影音按类型显示默认封面。
- 书影音卡片显示作品年份和我的记录 / 评分时间。
- 书影音评分显示为 `x/5`。
- 书影音评分同时显示五颗星视觉，并支持 0.1 颗星精度。
- 所有已发布书影音都可以进入详情页。
- 有长评的详情页展示长评正文。
- 无长评的详情页展示基础信息和短评，不出现空白主体。
- 随笔列表支持每页 6 篇分页。
- 书影音每个分类支持每页 6 条分页。
- 随笔、书影音、时间线在无内容或筛选无结果时有温和空状态。
- 桌面端左侧导航在右侧内容滚动时保持可见。
- 移动端没有因本版本桌面优化出现明显不可用问题。
- 不新增站内后台、登录、真实 AI、RAG 或私密内容能力。

## 后续版本方向

v0.2.2 可以单独规划时间线横向数轴，包括：

- 横向滚动时间轴。
- 数轴与记录卡片同步横向移动。
- 鼠标滚轮上下滚动映射为横向滚动。
- 当前可视范围内展示多条时间线记录。

这些内容不进入 v0.2.1，避免本小版本同时承担两个较大的交互改造。
