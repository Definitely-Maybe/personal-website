# v0.2.2 Navigation Controls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve desktop browsing control with detail breadcrumbs, a stable shared pagination control, fixed page headers/controls, and no width jitter during essay filtering.

**Architecture:** Keep changes in the existing Astro component model. Add small shared components for detail navigation and pagination markup, keep per-page behavior in scoped scripts, and let `ContentLayout` own the common sticky page header structure so all content pages inherit the same desktop behavior.

**Tech Stack:** Astro 5, TypeScript in Astro scripts, CSS in `src/styles/global.css`, Vitest, Playwright e2e with fixture content.

---

## File Structure

- Create `src/components/DetailNav.astro`
  - Renders breadcrumb links and the fixed “退出阅读” action for detail pages.
  - Takes breadcrumb items and exit target as props.
- Modify `src/components/Pagination.astro`
  - Replaces text-only previous/next buttons with first/previous/page-number/next/last controls.
  - Keeps existing `data-pagination` and `data-page-size` API.
- Modify `src/layouts/ContentLayout.astro`
  - Adds sticky-friendly header classes and an optional named `controls` slot below the page title.
  - Keeps current `title`, `eyebrow`, and `description` props.
- Modify `src/pages/essays/[slug].astro`
  - Adds `DetailNav` with `首页 / 随笔 / 当前标题` and exit to `/essays`.
- Modify `src/pages/reviews/[slug].astro`
  - Adds `DetailNav` with `首页 / 书影音 / 分类 / 当前标题` and exit to `/reviews`.
- Modify `src/pages/essays/index.astro`
  - Moves essay filters into the `controls` slot for sticky behavior.
  - Updates pagination script to render clickable page numbers and first/last controls.
  - Adds a stable width marker for Playwright verification.
- Modify `src/components/ReviewTabs.astro`
  - Moves tab controls into a slot supplied by `/reviews`, or keeps controls in component but marks them for sticky styling.
  - Updates per-tab pagination script to render clickable page numbers and first/last controls.
- Modify `src/pages/reviews.astro`
  - Provides sticky controls for review tabs if the tab controls are lifted out of `ReviewTabs`.
- Modify `src/styles/global.css`
  - Adds detail nav, sticky page header/controls, upgraded pagination, and stable essay layout styles.
  - Keeps desktop-first behavior; mobile falls back to normal flow.
- Modify `e2e/smoke.spec.ts`
  - Adds coverage for breadcrumbs/exit reading, page-number pagination, essay width stability, and sticky controls.

```astro
interface BreadcrumbItem {
  label: string;
  href?: string;
}

interface Props {
  items: BreadcrumbItem[];
  exitHref: string;
}

const { items, exitHref } = Astro.props;
---

<div class="detail-nav">
  <nav class="breadcrumbs" aria-label="面包屑">
    <ol>
      {items.map((item, index) => {
        const isCurrent = index === items.length - 1;
        return (
          <li>
            {item.href && !isCurrent ? (
              <a href={item.href}>{item.label}</a>
            ) : (
              <span aria-current={isCurrent ? 'page' : undefined}>{item.label}</span>
            )}
          </li>
        );
      })}
    </ol>
  </nav>
  <a class="detail-nav__exit" href={exitHref}>退出阅读</a>
</div>
```
